This is **json_config**, Nomisma's application configuration library based on JSON.
Its planned scope is Python configuration generation, C++ configuration discovery
and JSON/C++ mapping, and build-system integration. It shares its design with
`toml_config`; both implementations are intended to offer similar capabilities.
The repository currently contains the project scaffold, with nlohmann/json and
Metal inherited from `cmake_template`; configuration code is still to be added.
