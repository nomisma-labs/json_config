This is **json_config**, Nomisma's application configuration library based on JSON.
Its scope is Python configuration generation, C++ configuration discovery and
JSON/C++ mapping, and build-system integration. The Python resolution engine and
its tests are implemented. The generator CLI, C++ library, and generation-specific
CMake helpers remain to be added; the config collector and nlohmann/json dependency
are inherited from `cmake_template`.
